Scaffold — fsevents install script hung on pyenv; killed as optional

Context
The spec pre-probed fabric through the firewall but did not anticipate fsevents@2.3.3 (a transitive optional dep of Vite's watcher) running node-gyp rebuild. That build hung for 10+ minutes on pyenv exec python3 — the same hang visible in 21-hour-old stray node-gyp processes from other sessions on this machine.
Decision
Killed the hung pyenv/node-gyp subtree (PIDs 91255/91207). npm treats an optional dependency's script failure as non-fatal; npm install completed with exit 0 and fsevents is simply absent from node_modules. No impact on npm run build (green) or deploy; the only cost is Vite's dev-server file watching falls back from native FSEvents to its portable watcher.
Alternative
Waiting indefinitely for the pyenv shim (it never resolves — no stdin), or re-running with --omit=optional (would also drop fabric's optional canvas helper, which had already installed cleanly with code 0).
